# Workstream inputs

The inputs that state what this workstream is for. A run that names no workstream finds this one when one of its subject inputs is listed here and still asks for what its line says. Lines are appended, never changed or removed.

Line form: - `{key}` -- {what it asks for, in one line} (added {yyyy-MM-dd})
Keys: a repo-relative file path with forward slashes; `#{n}` for an issue or pull request in this repository, `{owner}/{repo}#{n}` for another; `conversation` for a request stated only in conversation.
